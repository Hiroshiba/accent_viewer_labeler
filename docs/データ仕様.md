# データ仕様

本ツールが扱うデータは以下の 6 種類のファイルで構成される。

- .lab ファイル（必須）
- accent_start フラグファイル（必須）
- accent_end フラグファイル（必須）
- accent_phrase_start フラグファイル（必須）
- accent_phrase_end フラグファイル（必須）
- 音声ファイル（任意）

各ファイルは stem（拡張子なしファイル名）で対応づけられる。

## .lab ファイル

Julius 形式。スペースまたはタブ区切り 3 カラム。

```
{開始時刻} {終了時刻} {音素}
```

- 時刻は秒単位の浮動小数点
- 先頭行と末尾行は `pau`（無音）
- フレーズ間に途中 `pau` が入ることがある（1 ファイルに 3 個以上の pau を含む場合がある）

### OJT 音素セット

- 母音: `a`, `i`, `u`, `e`, `o`
- 無声母音（大文字）: `A`, `I`, `U`, `E`, `O`
- 子音: `k`, `s`, `t`, `n`, `h`, `m`, `y`, `r`, `w`, `g`, `z`, `d`, `b`, `p`, `ky`, `sh`, `ch`, `ny`, `hy`, `my`, `ry`, `gy`, `j`, `dy`, `by`, `py`, `ts`, `f`
- 特殊: `N`（撥音）, `cl`（促音）, `pau`（無音）

長母音は `o:` のようなコロン表記ではなく、`o u` のように 2 音素で表す。

### モーラへの変換

pau を除外した音素列を先頭から走査し、以下のルールでモーラに変換する:

- 母音単独 → 1 モーラ（例: `a` → あ）
- 子音 + 母音 → 1 モーラ（例: `k a` → か、`sh i` → し）
- `N` → ん
- `cl` → っ

## アクセントフラグファイル

スペース区切りの `0`/`1` 列。1 行のみ。

- フラグ数は .lab ファイルの全音素数（pau 含む）と一致する
- pau 位置のフラグは常に `0`
- 子音 + 母音で 1 モーラを構成する場合、両方の音素で同時にフラグが立つ

### accent_start

アクセント核の直後（下降開始位置）を示す。

### accent_end

アクセント核の位置（最後の高音素）を示す。

### accent_phrase_start

アクセント句の先頭音素を示す。

### accent_phrase_end

アクセント句の末尾音素を示す。

### アクセント位置の算出

各アクセント句内で最初の `accent_start` フラグの位置を `p` とすると:

- `p == 0`（句頭）→ アクセント位置 = 0（平板型）
- `p > 0` → アクセント位置 = `p - 1`
